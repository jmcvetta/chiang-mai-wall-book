# Place-name glossary

Status: unreviewed research staging, started 2026-10-08 for issue #3. Not book content.

The glossary keeps four kinds of name apart:

- **Thai form**: the Thai spelling a source uses.
- **Variant**: another spelling or a former name that a source records.
- **English form**: the form this inventory uses. It is a romanisation chosen for consistency. It is not an official English name unless a source says so.
- **Editorial name**: a name coined for this book. Nobody else uses it.

No name here encodes a date or a phase. A source that uses a name is not evidence about the age of the fabric.

Thai romanisation has not been reviewed by a competent reader. Consequential spellings need that review before publication.

`แจ่ง` (chaeng) is the Northern Thai term for a corner of the city wall. Wikipedia glosses it as มุม (corner) and calls the four corners the city's former strongpoints (ป้อมปราการ). That gloss is a lead for the book's explanation of the term, not yet a reviewed definition.

## "North Gate"

The planning document starts the route at "the North Gate". Thai Wikipedia describes ประตูช้างเผือก as the inner gate on the north side (th-wikipedia-wall-r13016262). This inventory therefore uses "North Gate" as a route description for Chang Phueak Gate. It is not a second name for it.
